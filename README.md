# Аида — это история о нас

Fullscreen-сайт: фотографии на весь экран, по центру красивый текст, при прокрутке вниз фото и надписи плавно меняются.

## Где менять текст и фото

Главный файл:

`src/data/slides.js`

В нём можно менять фотографии, заголовки, подзаголовки, основной текст и порядок экранов.

Пример одного экрана:

```js
{
  image: '/photos/photo1.jpg',
  title: 'Аида',
  subtitle: 'Это история о нас',
  text: 'О моментах, которые хочется сохранить...',
}
```

## Фотографии

Фотографии кладутся в папку:

`public/photos/`

Сейчас в коде прописаны имена: `photo1.jpg` ... `photo8.jpg`.

## Музыка

Музыка кладётся сюда:

`public/music/song.mp3`

Кнопка музыки находится справа снизу. Музыка запускается только по нажатию.
